Off-grid buyers usually need more than module pricing. They need a package that connects PV capacity, inverter selection, battery storage and load assumptions.

## Dealer checklist

- Target load and daily energy consumption
- Backup duration requirement
- Battery capacity and battery chemistry
- Inverter type and surge requirement
- Installation environment and climate
- Maintenance and after-sales expectations

## Recommended sales path

Start with the use case, then show a package reference, then confirm BOM details. This helps dealers avoid quoting modules without understanding system requirements.

## Documentation to prepare

Dealers should prepare datasheets, system topology diagrams, installation guides and warranty documents before customer negotiation.
