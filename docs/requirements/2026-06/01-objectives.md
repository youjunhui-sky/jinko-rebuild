# 01. 目标与定位

## 核心目标（客户明示）

| 优先级 | 目标 | 说明 |
|---|---|---|
| **P0** | B 端询盘（外贸客户） | 全站围绕 "Inquiry / RFQ" 转化设计 |
| **P1** | SEO 流量获取 | 长尾词 + 三级结构 + 内容运营 |
| P2 | SEM（Google Ads）承接 | 独立 Landing Page + Conversion Tracking |

> 客户原文：「当前网站核心目标：第一优先级：B端询盘（外贸客户）；第二优先级：SEO流量获取，所以需要把未来 SEO / SEM / 内容运营 / 询盘转化 的基础设施预留好。」

## 目标客户（来自「安装案例」sheet 第二段战略说明）

切入 **晶科（JinkoSolar）在美国的二、三级代理商**：
- Distributors（区域分销商）
- Dealers
- EPC Installers（中小型 EPC、地方居家/工商业屋顶安装商）

### 这些客户的三大痛点（必须在网站中正面回应）

1. **产品质量稳不稳定** → 会不会被业主频繁售后投诉？
2. **供货够不够灵活及时** → 会不会卡他们的工期？
3. **是否有可复用的标准化案例** → 中小型 C&I（工商业）和 DG（分布式）上有没有现成的 BOM / 经验 / 案例？

## 内容长期规划（站点必须可扩展承接）

后续会持续新增的页面类型：
- 博客 Blog
- 新闻 News
- 行业内容 Industry
- 产品方案页 Solutions
- 工程案例 Cases
- OEM 页面
- 展会活动（未来扩展）
- 合作伙伴（未来扩展）

→ 这要求：**可扩展的页面结构 + 分类体系 + 后台内容管理 + URL 层级结构**。
