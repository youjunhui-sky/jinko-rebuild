### 5. 旧 URL / sitemap / noindex 清理

处理旧路径：

```text

/eagle-storage/
/homeowners/
/installer-finder/
/jacksonville/
/tiger-neo/
/warranty/
/news/
/news/[slug]/

/es/
/zh/
```

处理方式：

- 旧页面 noindex + nofollow
- meta refresh + JS redirect
- sitemap filter 排除旧路径
- robots.txt 增加 Disallow

限制：当前 Cloudflare Workers 静态模式未做服务端 301。正式域名上线时如需严格 301，可用 Cloudflare Redirect Rules 或自定义 Worker redirect。

### 8. Turnstile 防垃圾预留

新增：

```text
SITE.security.turnstileSiteKey
TURNSTILE_SECRET_KEY
```

逻辑：

- site key 为空：前端不显示 Turnstile
- secret 为空：后端不强制校验
- secret 存在：后端校验 `cf-turnstile-response`

验证：

- 无 secret：有效表单 200 mock success
- 有 secret 无 token：400 `missing_turnstile`
